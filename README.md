# CodeAlpha_StockPortfolioTracker

Simple stock portfolio tracker for the CodeAlpha Python internship (Task 2).

## What it does
- Shows a hardcoded price list (`AAPL`, `TSLA`, `GOOGL`, `MSFT`, `AMZN`).
- User enters a symbol and quantity, as many times as they want.
- Prints total investment value.
- Optionally saves the result as `portfolio.txt` or `portfolio.csv`.

## How to run
```bash
python portfolio_tracker.py
```

Example:
```
Symbol: AAPL
Quantity: 2
Symbol: TSLA
Quantity: 1
Symbol: done
```

## Concepts used
dictionary, input/output, basic arithmetic, file handling.
